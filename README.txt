# Couple Love Website ❤️

## Included
- Responsive desktop/mobile design
- Floating hearts
- Heartbeat animation
- Glassmorphism cards
- Scroll reveal animations
- Love counter from 17 June 2017
- Wedding countdown to 11 November 2026, 9:15 AM
- Wedding time: 9:15 AM – 10:15 AM
- Relationship timeline
- Animated photo gallery with full-screen viewer
- Romantic letter and surprise button
- Your 5 uploaded photos included locally

## Run
Open `index.html` in Chrome/Edge.

## Edit
Open `index.html` and change:
- Couple wording/names
- Timeline text
- Engagement year if required
- `loveStart` if the love counter should use a different date
- `weddingStart` if the wedding time/date changes

## Photos
All uploaded photos are stored in `assets/`.
